# 发布验证记录

日期：2026-10-25。范围：从上游历史建立的独立公开目录，包含当前 ESP32/ST7789 固件、Windows 客户端和必要的三个随附库。

## 本次可重复验证

- 57 项 Python unittest 通过，覆盖 API 解析、双窗口、时间、负载上限、动作白名单、配对保护、断电后临时失败恢复、WinRT 服务清理、旧连接回调和实例锁。使用现有 Bleak 1.1.1 环境，未连接用户设备。
- 独立目录 `platformio run -e magpie-esp32` 成功，Espressif32 6.10.0 / Arduino-ESP32 2.0.17。静态 RAM：41,972 / 327,680 字节；Flash 程序：1,315,621 / 3,145,728 字节。另需运行时分配 76,800 字节显示缓冲和 BLE 堆。
- 四页、额度边界、连接/配对布局与动画由 `preview_magpie_dashboard.py` 重新生成；桌面配图使用离线示例模式下的真实 Tk 组件。
- 独立公开目录新建 Python 3.13 隔离环境，安装 Bleak 1.1.1 与 PyInstaller 6.22.3 后成功生成 EXE；该新环境再次通过 57 项测试。EXE 执行 `--help` 启动检查返回 0，不连接蓝牙。完整依赖版本和许可证随 Windows ZIP 提供。

TFT_eSPI 编译时会提示未定义触摸 CS，这是按键版未配置触摸的预期提示。

## 不能据此推断的结果

本次公开准备没有烧录或复位用户硬件。最终双额度动画固件的实际色彩、帧率、按键和长时间稳定性仍需实机确认。1.3.1 的断电恢复与原生句柄释放通过模拟回归；最终 EXE 的完整普通断电恢复循环仍需实机验证。

本地已有记录曾确认更早版本可以完成加密 GATT 传输，也记录过 Windows 已配对但设备绑定不一致的故障；这些不等同于本次最终发布版的全面实机认证。首次配对仍应使用系统设置输入验证码。

仓库图片均注明为示例，不使用上游另一款硬件的实机照片冒充当前设备。macOS CLI 留有既有平台分支，但此移植版发布验证聚焦 Windows；不宣称 GUI 跨平台。
